# Daily Bible Verse App (React)

This is a simple React application that displays a random Bible verse to provide encouragement and reflection for different moments in life. Users can select a general mood or situation, and the app will fetch and display a relevant Bible verse.

## Features

- Select from predefined categories (e.g., "Feeling Anxious," "Needing Comfort").
- Fetches a random Bible verse from the [bible-api.com](https://bible-api.com/) API (using the King James Version by default).
- Displays the verse reference, text, and translation.
- Button to fetch another random verse.

## API Used

This application uses the free Bible API available at [bible-api.com](https://bible-api.com/). Please be mindful of their terms of use, especially regarding rate limits if you intend to modify or heavily use this application.
